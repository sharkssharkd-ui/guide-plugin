Этап 1: Фундамент

Прежде чем строить дом (плагин), нужно подготовить инструменты. Если пропустить этот этап или сделать его кое-как — ничего работать не будет.

1. Java Development Kit (JDK)

⛔️ ВНИМАНИЕ!

Не путай JRE (чтобы играть) и JDK (чтобы программировать). Тебе нужен именно JDK.

Какую версию выбрать?

  • Minecraft 1.16.5 – 1.20.4: Качаем JDK 17.
  • Minecraft 1.20.6 – 1.21+: Качаем JDK 21.

Пошаговая инструкция:

  1. Перейди на сайт Adoptium.net.
  2. Нажми кнопку Latest LTS Release.
  3. Скачается файл .msi. Запусти его.
  4. САМЫЙ ВАЖНЫЙ МОМЕНТ: На экране "Custom Setup" найди пункт "Set JAVA_HOME variable". Там будет красный крестик. Нажми на него и выбери "Will be installed on local hard drive".
  5. Нажимай Next до конца.

2. Среда разработки (IDEA)

Мы будем писать код в IntelliJ IDEA. Это "Мерседес" среди программ для Java.

1. Скачай Community Edition (она бесплатная).
2. При установке поставь галочку "Create Desktop Shortcut".
3. Остальное можно оставить по умолчанию.

3. Локальный сервер

Никогда не тестируй плагины на хостинге. Это долго. Создай сервер у себя на ПК.

start.bat
java -Xms2G -Xmx2G -jar paper.jar nogui
pause

1. Создай папку на рабочем столе.
2. Скачай ядро PaperMC и положи в папку.
3. Переименуй скачанный файл в paper.jar.
4. Создай текстовый файл, вставь код выше и сохрани как start.bat.
5. Запусти, прими EULA (в файле eula.txt поменяй false на true) и запусти снова.
