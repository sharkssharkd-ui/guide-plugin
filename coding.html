Этап 3: Магия кода

Теперь, когда Java установлена, а Maven настроен, пришло время написать сам плагин.

1. Структура проекта

В IntelliJ IDEA слева ты увидишь дерево папок. Нас интересуют только две:

  • 📂 src/main/java — здесь лежит Java код.
  • 📂 src/main/resources — здесь лежат конфиги (plugin.yml, config.yml).

🧠 Правило пакетов

В папке java нельзя создавать классы просто так. Нужно создать пакет (папку с точками).
Принятый стандарт: ru.твойник.названиеплагина.
Пример: ru.alex.megaplugin.

2. Главный класс (Main)

Создай в своем пакете файл Main.java. Это сердце твоего плагина.

Он ОБЯЗАН наследовать класс JavaPlugin. Без этого сервер не поймет, что это плагин.

Main.java
package ru.alex.megaplugin;

import org.bukkit.plugin.java.JavaPlugin;

public class Main extends JavaPlugin {

    @Override
    public void onEnable() {
        // Этот код сработает при включении сервера
        getLogger().info("Плагин успешно ЗАПУЩЕН!");
    }

    @Override
    public void onDisable() {
        // Этот код сработает при выключении
        getLogger().info("Плагин ВЫКЛЮЧЕН!");
    }
}

3. Паспорт плагина (plugin.yml)

⛔️ САМАЯ ЧАСТАЯ ОШИБКА

Если ты укажешь неправильный путь в строке main:, сервер выдаст ошибку "Cannot find main class".

Путь должен состоять из: ПАКЕТ + ИМЯ КЛАССА.

Создай файл plugin.yml в папке src/main/resources (не в java!).

src/main/resources/plugin.yml
name: MegaPlugin
version: 1.0
# ВНИМАНИЕ НА СТРОКУ НИЖЕ:
main: ru.alex.megaplugin.Main
api-version: 1.20
authors: [Alex]

4. Сборка проекта (Build)

Код написан. Теперь нужно превратить его в файл .jar, который можно закинуть на сервер.

  1. В IntelliJ IDEA справа найди вертикальную вкладку Maven.
  2. Раскрой список: Lifecycle.
  3. Дважды кликни на package (не install, не deploy, а именно package).

Если внизу в консоли написано BUILD SUCCESS — поздравляю!

Твой готовый плагин лежит в папке проекта: target/MegaPlugin-1.0.jar.

5. Использование ИИ (Gemini / Qwen)

Теперь, когда у тебя есть база, пусть остальное пишет нейросеть. Но нужно уметь просить.

💡 Формула идеального промпта

[РОЛЬ] + [ТЕХНОЛОГИИ] + [ЗАДАЧА] + [УСЛОВИЯ]

Пример запроса к ИИ
Ты Senior Java Developer. Пишем плагин под Spigot 1.20.4.

Задача: Напиши класс-листенер (Listener).
Логика: Когда игрок ломает блок алмазной руды, с шансом 50% ему выпадает сообщение в чат "Тебе повезло!", а с шансом 50% бьет молния.

Условия:
1. Используй ThreadLocalRandom для рандома.
2. Не используй устаревшие методы (deprecated).
3. Код должен быть готов к вставке (copy-paste).

🎉 Поздравляю!

Ты прошел путь от установки Java до создания своего первого плагина.

Теперь просто копируй .jar файл в папку plugins своего сервера и запускай!
